# 真题题库：收集、转写、验算、使用

有历年卷时，先把它们整理成**真题题库**，再拿题库去做真题驱动的主讲义、期末复习页、小测题型池。题库是给讲义作者用的中间件，不发布。2026-10 做过三门：复变 15 卷 212 小题，大学物理期末与小测，电子电路一年回忆卷 25 小题。

流程：收集归档 → 分卷转写 → 自解与验算 → 汇总 → 复核答案卷错误与存疑 → 用于讲义。题量大时按[协作模式](collaboration.md)分工：一个杂工负责一套卷，另一个杂工复核，总领看原图裁决。

## 1. 收集与归档

- **来源**：学校论坛（如 CC98）、GitHub 上的课程资料仓库、学长整理的合集。只下载原卷和答案。网盘资料下不了的，记下帖子号，留给用户决定。
- **命名**：`YYYY-YYYY秋冬期末_<内容>(<整理者>).<扩展名>`，例如 `2024-2025秋冬期末_试卷+答案.pdf`、`2025-2026秋冬期末_回忆卷(某某).pdf`。统一放在 `<课程>/历年卷/`。
- **归档记录**：`制作记录/工作资料/<简称>历年卷归档.json`。每个文件记来源（帖子号或 URL）、原文件名、SHA-256、备注。
- **年份按卷头核对**，不信文件名。CC98 上曾把两份卷子的年份标反。外校卷、外院卷要标出来，例如“华科复习题”“疑为数院卷”。缺哪几年也记下来。
- **格式转换**：`.doc`、`.ppt` 用 ONLYOFFICE 的 `x2t`（或 LibreOffice）转成 PDF，原件保留，文件名加 `(ONLYOFFICE转)`。MathType 公式里的 Symbol 字体会显示成 Latin-1 字母（p→π、Þ→⇒），对照表放进归档 json。

## 2. 分卷格式

每套卷一个文件 `制作记录/工作资料/<简称>题库分卷/<key>.md`。key 的写法：`f2324` 表示 2023—2024 期末，`m2526` 表示期中，`hk1` 表示外校。

```markdown
# f2324 2023-2024秋冬期末（共 100 分，12 小题）

来源：`2023-2024秋冬期末_试卷+答案.pdf` 第 1–5 页；答案：同卷。考试 2023-11-18，闭卷。

## 一、（每题 8 分）

- 一(1)（8分）题干：……（照抄原卷；电路、图形题把拓扑和参考方向写成文字，另附原图路径）
  答案：……
  推导：……（关键中间式都写出来，讲义会直接用）
  核对：答案卷 = ……；独立重算 ✓（脚本项 `f2324-1-1`）
  **知识点**：<讲义小节 id> / <id>；**范围**：范围内

## 存疑

1. 一(4)：……（读法不确定的地方，给主读法、备选读法和备选读法下的答案）

## 答案卷问题

1. 二(2)：答案卷 = ……，正确为 ……，证据：脚本项 ……
```

- **知识点**写讲义的小节 id。讲义还没讲到的章节用占位 id（如 `laurent`、`residue`），讲到时替换成真实 id。
- **范围**取“范围内 / 部分范围内 / 后续”三者之一，按讲义当前进度标。
- **回忆卷**：题干照抄回忆者原文。照片和手绘图必须由能看图的模型亲自读，总领要复核。电子电路期末题库曾在没看图的情况下整理，6 道大题读错了 3 道。图上读法有疑问时，总领写一份“原图核对”文件作为权威读法，题库按它更正。
- 没有答案卷的题（回忆卷常见），“核对”一栏写“无答案卷；独立重算 ✓”。

## 3. 自解与验算

每卷一个脚本 `制作记录/核验/<简称>题库/<key>.py`。运行后写同名 `<key>.json`：

```json
{"total": 18, "passed": 18, "items": [{"id": "f2324-1-1", "desc": "...", "pass": true, "detail": "..."}]}
```

- **每个小题独立重算**，不抄答案卷。按学科选工具：
  - 复变：sympy 级数展开、mpmath 数值围道积分、数值拉氏变换、映射边界点检验；
  - 概率：分数精确计算、枚举、蒙特卡洛模拟；
  - 电路：小型 MNA 节点电位求解器；
  - 物理：sympy 符号推导配合数值积分。
- 推导里的关键中间式也要核，不只核最终答案。讲义会直接用这些中间式。
- 重算结果和答案卷不一致时，写进“答案卷问题”，附证据（脚本项 id 和数值）。

## 4. 汇总

```bash
python3 $S/exam_bank.py <简称>
```

卷序和题库开头的说明写在分卷目录的 `题库配置.json`（`{"order": [...], "header": "..."}`）里。脚本做三件事：

- 拼出 `工作资料/<简称>真题题库.md`（这是拼接稿，不要直接改，改分卷后重跑）；
- 运行全部验算脚本；
- 统计小题数、范围分布、知识点出现次数，写进 `核验/<简称>真题题库核验.json`。

它还会核对每卷小题数与“范围”标签数是否相等，不相等就报问题。

## 5. 复核

- 由另一个代理（不是写这卷的那个）逐条复核全部“答案卷问题”。
- 存疑和答案卷问题的条数、结论写进本课制作记录的“真题题库”一节。同时记下：
  - 来源帖子号；
  - 缺失的年份；
  - 知识点出现次数最多的前几项（复变：留数 41、保角映射 30、解析性 27）。这几项决定复习的重点和题型池的顺序。

## 6. 用题库做讲义

- **真题驱动主讲义**：见 mainlines.md“真题驱动”。范围内的小题放进对应小节开头作【真题】例，或作小节习题；超范围的注明“第 X 章再做”。题库每个小题在覆盖表里占一行。
- **期末复习页**（题型归纳主线的期末版）：
  - 每个题型池依次是：知识点 → 固定动作 → 易错（“错误做法 → 错在哪里 → 正确做法”）→ 池中全部题目表 → 题目（主线题、跳脱题、更多真题折叠）。
  - 最后一单元放限时模考（原卷原样排出），再加概念检查和来源说明。
  - 独立页面，单独的构建配置和中文字体子集。
- **真题少时**（例如只有一年回忆卷）：每池的知识点写全（定义、带条件的定理、公式来历、最小算例），题目分三层：【真题】→ 课本同型题（每池 2—4 道）→ 更多。
- **讲义推进后**：把占位 id 换成真实小节 id，范围标签跟着改，重跑 `exam_bank.py`。
